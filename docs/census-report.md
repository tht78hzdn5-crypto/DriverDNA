### Driver Model confidence

Confidence is the mean of these four ratios, each capped at 1.0 (model `dm-v2`). A term at its floor is saturated — more of it buys exactly nothing. Current ceiling for a measured fundamental: **60.2%** (a proxy fundamental is additionally capped at 50%).

| gate | have / need | status | unblocks |
|---|---|---|---|
| evidence laps | 12/50 | **short** | the volume quarter of every belief's confidence |
| sessions | 3/6 | **short** | the session-breadth quarter of confidence |
| tracks | 2/3 | **short** | the track-breadth quarter of confidence |
| cars | 2/2 | met | the car-breadth quarter of confidence |

- to close **evidence laps**: import more laps in any cohort (`driverdna sync`, `driverdna import`, or #/upload).
- to close **sessions**: drive on more separate occasions — one session is one sitting, not one lap.
- to close **tracks**: import laps from another track (a track variant counts as its own cohort).

### Trend availability

Trend compares a fundamental's score between an earlier and a recent bucket of dated laps. An undated lap can still score — it just cannot be placed in time, so it never contributes a direction.

| gate | have / need | status | unblocks |
|---|---|---|---|
| dated laps | 0/8 | **short** | `trend` on every fundamental (4 dated laps in each of the earlier and recent halves) |

- to close **dated laps**: `driverdna sync` sets lap_date from the API automatically; for manual CSVs use `driverdna import --date YYYY-MM-DD`.

### Reference laps

Reference laps are structurally isolated: they never enter self history, trends, or consistency statistics. `sync` cannot fetch them (other drivers' telemetry returns 403), so the manual import path is the only way in.
