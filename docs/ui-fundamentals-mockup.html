What is the same in all four, and stays that way. Every finding row keeps its own source tag — the three sources are never blended (SPEC decision 3). No group header carries an aggregate: a per-fundamental seconds total would double-count, because cumulative_loss is per phase and entry maps to two fundamentals. The header shows a name and a count of rendered rows, nothing else. Suppressed findings are collapsed, never dropped, each with its exact gate reason. The order is the Driver Model pyramid's fixed order, so it never implies a ranking.

Two honest edge cases are in every variant. Braking has findings but no coaching principle eligible — no sentence is invented for it. Consistency is the reverse: a major coaching signal at 16 corners with zero findings clearing the gates, which is exactly the case the current layout renders as a bare "Nothing clears the gates here yet."

The tier mark beside each name is the settled shared device: seven tiers, this fundamental's lit, the same glyph on the Driver Model tab. It encodes position in the fixed seven — never a score, never a colour with meaning.
